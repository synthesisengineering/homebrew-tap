# Synthesis Homebrew tap

Versioned installation commands for Synthesis, SlopCheck, Synthesis Console and Ownwords.
Each formula downloads an exact GitHub release archive and checks its SHA-256.
Installation does not enroll a workspace, enable agent hooks or start services.
Run the installed command's explicit setup operation to choose adoption settings.

The installation guide and component comparison are at https://synthesiswork.org/download/.
Updates use normal Homebrew operations and are never forced by these packages.
